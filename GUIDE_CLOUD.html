🌐 150명 이상 대회 준비하기

퀴즈 프로그램을 인터넷 서버에 올려 두면, 진행자 컴퓨터를 켜 두지 않아도
몇백 명이 휴대폰 데이터·와이파이 어디서나 들어올 수 있어요.

어떤 방법을 쓸까요?
참가 인원추천 방법
~100명내 컴퓨터에서 START_Windows.bat 더블클릭 (GUIDE.html 참고)
100명 이상
또는 중요한 대회		이 안내서대로 인터넷 서버(Render)에 올리기 ← 처음 한 번 20~30분
준비물: 이메일 주소 1개 (무료 가입 2곳: GitHub, Render) · 받은 quiz-app.zip 압축 푼 폴더
※ 사이트 화면은 영어예요. 아래에 누를 버튼 이름을 그대로 적어 두었어요. 사이트가 바뀌어 글자가 조금 다를 수 있어요.

1단계. GitHub에 퀴즈 파일 올리기 (파일 보관함)

1가입하기

github.com 접속 → Sign up → 이메일·비밀번호·사용자 이름 입력 → 이메일로 온 숫자 입력.

2보관함(저장소) 만들기

오른쪽 위 + → New repository
• Repository name: bible-quiz
• Private 선택 (비공개 — 정답이 다른 사람에게 보이지 않게)
• 맨 아래 Create repository

3파일 올리기

화면 가운데 uploading an existing file 글자를 눌러요.
압축 푼 quiz-app 폴더를 열고, 그 안에 있는 파일과 public 폴더를 모두 선택해서 화면에 끌어다 놓아요.
업로드가 끝나면 아래 초록색 Commit changes.
⚠️ quiz-app 폴더 자체가 아니라, 폴더 “안의 내용물”을 끌어다 놓아야 해요.
올린 뒤 목록 맨 위에 public, render.yaml, server.js 등이 바로 보이면 성공!

2단계. Render에서 인터넷 서버 켜기

1가입하기

render.com 접속 → Get Started → GitHub 버튼으로 가입 (방금 만든 GitHub 계정으로 로그인 → Authorize).

2퀴즈 서버 만들기

위쪽 + New → Blueprint
GitHub 저장소 목록이 안 보이면 Configure GitHub(또는 Connect) → bible-quiz를 선택해 허용해 주세요.
목록에서 bible-quiz 옆 Connect.

3진행자 비밀번호 정하기

HOST_PASSWORD 칸에 진행자 비밀번호를 적어요. (예: gibmap2026, 참가자에게 알려 주지 마세요)
Blueprint Name 칸이 있으면 아무 이름(예: bible-quiz)이나 적고 → Deploy Blueprint (또는 Apply).

4주소 확인하기

2~5분 기다린 뒤 Dashboard → bible-quiz를 누르면 위쪽에
https://bible-quiz-xxxx.onrender.com 같은 내 퀴즈 주소가 있어요. 이 주소를 적어 두세요.
✅ 이제 준비 끝! 이 주소는 바뀌지 않아요. 다음 대회 때도 그대로 쓰면 돼요.

3단계. 대회 진행하기

1 진행자 컴퓨터 인터넷 창에 내 퀴즈 주소 뒤에 /host를 붙여 열어요.
    예) https://bible-quiz-xxxx.onrender.com/host
2 진행자 비밀번호를 넣고 들어가기.
3 QR코드 아래에 ✅ 인터넷 어디서나 접속할 수 있어요가 보이면, 화면을 TV·빔프로젝터에 띄우고 QR코드를 찍게 하세요.
4 그다음은 원래 사용설명서(GUIDE.html)와 똑같아요. 🎲 문제 내기 → 정답 공개 → 🏆 순위.
⏰ 대회 10분 전에 꼭 진행자 화면을 먼저 열어 두세요.
무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 잠든 서버는 처음 열 때 1분쯤 걸려요. 미리 열어 두면 참가자는 기다리지 않아요.

🔁 서버가 잠들거나 다시 켜지면 참가자 명단과 점수가 지워져요. 대회 중에는 진행자 화면을 켜 둔 채로 진행하세요.
(대회 중에 지워지면 참가자 휴대폰에 “다시 입장해 주세요”가 나와요. 다시 입장하면 돼요.)

문제를 고쳤을 때

진행자 화면 📝 문제 관리에서 고칠 수 있어요. 하지만 인터넷 서버가 다시 켜지면 처음 문제로 돌아가요.
계속 쓰려면: 💾 문제 파일로 내려받기 → 받은 questions.json을 GitHub의 bible-quiz 보관함에 다시 올리기
(Add file → Upload files → 끌어다 놓기 → Commit changes). 몇 분 뒤 서버에 자동으로 반영돼요.
급할 때는 대회 시작 전에 📂 문제 파일 불러오기로 바로 넣어도 돼요.

자주 묻는 질문

돈이 드나요?무료 요금(Free)으로 충분해요. 서버가 잠들지 않게 하고 싶으면 Render에서 Starter(월 약 7달러)로 바꿀 수 있어요. 큰 대회 한 달만 바꿨다가 다시 Free로 돌려도 돼요.
몇 명까지 되나요?350명이 동시에 답을 내는 시험에서 모두 정상 처리됐어요. 몇백 명 규모는 괜찮아요.
참가자가 진행자 화면을 열 수 있나요?아니요. 진행자 비밀번호가 있어야 열려요.
휴대폰 인터넷이 느린 사람은 불리한가요?걸린 시간은 각자 휴대폰에 문제가 도착한 순간부터 재요. 인터넷 속도 차이로 손해를 덜 보게 했어요.
진행자 비밀번호를 바꾸려면?Render → bible-quiz → Environment → HOST_PASSWORD 수정 → 저장 (서버가 다시 켜져요)
대회가 끝나면?그대로 두면 알아서 잠들어요. 다음 대회 때 같은 주소로 다시 쓰면 돼요.
